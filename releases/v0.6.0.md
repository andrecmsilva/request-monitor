# Request Monitor v0.6.0

Safety-direction release: Request Monitor is now snapshot-only.

- self-expiring 5–300 second capture windows
- default lightweight profile with no global hook profiler
- explicit hooks/deep short-window profiles
- idle MU and frontend fast paths
- capture session-scoped fingerprint results
- safe migration from legacy v0.5 continuous state

Recommended first run:

```bash
wp request-monitor capture 30s
```
